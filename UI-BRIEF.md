# Pinion Launcher — UI Brief

Build a desktop **launcher UI** for a custom **Minecraft Java** client called **Pinion**.

Quality reference: **Lunar Client**, **Feather Client**. That tier.

That is the scope. Everything else — feature set, information architecture, layout, navigation,
design language, components, motion — is **your call**. Decide it yourself; don't ask what to put
in. That judgment *is* the test. This build will be compared against another, independent one.

Only hard constraints (nothing about design):
- **React + TypeScript, runnable via Vite** — so it can actually be launched, viewed, compared.
- **Runs standalone** — mock whatever data it needs; no backend required to see it.
- It's a **desktop launcher**, not a marketing website.

Show your best.
